# 编排、负荷与进阶

以下数字是健康成年普通训练者的可调整起点，不是所有人的硬阈值。证据与编排启发式的区别见 evidence.md。

## 阶段主线

内部记录目标及主次、阶段观察周期、训练结构、可比锚点和评估指标。训练频率不稳定时用实际训练次序与滚动覆盖，别按星期机械补课。阶段变化只需在每日安排依据中解释。

| 方向 | 起始策略 | 观察与调整 |
|---|---|---|
| 增肌 | 选择可重复的动作覆盖目标肌群；从能恢复的组量开始；常见动作用 6–15 次或其他适合动作的范围 | 同动作表现、目标肌群覆盖、持续恢复；不把每肌群约 10 组/周等证据概括当新手第一周必达量 |
| 力量 | 围绕目标动作反复练习；新手先熟练再逐步加负荷；熟练者可用较低次数与充分休息 | 可比动作、动作范围、负荷/次数；不为校准强迫测极限或冲 PR |
| 减脂/体成分 | 保留有效力量训练，逐步增加能持续的有氧与日常活动 | 体重/腰围趋势与力量表现；训练量不以单次消耗最大化；不靠一个体重数字或照片 App 定热量缺口 |
| 心肺耐力 | 明确项目与当前连续运动能力，先建立可持续基础，再按需加入强度 | 同条件下时间、距离、配速/功率、体感；先增一个变量，间歇不作为无基础用户的默认开局 |
| 综合体能 | 明确最重要的一两项能力，其余维护；覆盖蹲、髋铰链、推、拉及按需单腿/携行/稳定 | 同时看各品质进展与干扰；不强制每次塞入所有模式、爆发或复杂功能动作 |
| 健康习惯/体验 | 简单可重复的全身动作与适量有氧，先让频率和剂量适合现实 | 完成率、耐受、偏好、日常能力；没有数据不承诺体形变化 |

## 下一次选择顺序

1. 用最近实际记录标记各模式负荷、表现、训练间隔与不适。缺失不是零训练。
2. 排除症状、未恢复高负荷和不可用器械；确认当日是否值得训练或需要休息。
3. 在阶段目标下找覆盖缺口，比较就绪度、同日干扰和对下次的影响。
4. 选一个主目标，最多一个次重点；随后确定动作。保留可比较锚点，变化应服务于目标或限制。
5. 核对实际总时长和可恢复训练量。重力量、复杂技术与高质量爆发需要充分休息，不为追心率赶组。

久未练腿或某模式：视为该模式重新适应，不因为上肢有基础就恢复旧腿部容量。可先选低复杂度动作和少量正式组，结合次日反应增加。新手不默认安排高难度杠铃复合动作、跳跃或练到失败。

## 负荷校准

- 已知同动作同器械负荷：引用日期和实际完成情况决定维持或调整，不用估算 1RM 覆盖真实记录。
- 未知：先轻负荷熟悉并逐级试重，避免在准备组耗尽。正式组使用完成规定次数后，估计还能标准完成约 2–4 次的负荷；这是操作提示，不是证据证明的精确最佳强度。
- 杠铃明确总重、哑铃明确单只、器械记录机器/座椅或档位。体重动作可调支撑高度、辅助或动作难度。
- 无法判断技术的新手，用更简单版本并建议现场教练确认器械设置；不要求自行挑战力竭确认重量。

## 当次加减规则（必须具体到动作）

- 首组明显轻松：已熟悉的动作可小幅加到下一可用档，新手可先保持记录，不因“没酸”加练。
- 首组未达下限或明显变形：停组，检查设置与休息；按最小可用档或约 5–10% 降重后重试。若一次档位跳幅过大，改次数/更容易版本；不对所有器械硬套百分比。
- 后续小幅掉次数但仍在目标范围：可保持，必要时延长休息。低于下限或动作持续失控：降重或删减后续组，不强迫补齐。
- 疼痛不是降一档继续测的理由，停止相关动作，按症状决定替换或结束。

## 下次进阶与减量

对常规、可比较的增肌/基础力量动作，可采用“双进阶”默认：同负荷全部组达到次数上限，动作稳定且无痛，并在再次暴露时得到确认，再增加最小可用负荷，次数回到范围下端。该两次确认是默认启发式，可按经验与动作调整，不宣称生理定律。

不同时增加负荷、组数和密度。力量专项、爆发、跑步/有氧不能机械套同一规则：力量看目标动作与负荷质量，爆发看输出质量，有氧一次调整时间/速度/坡度/强度中的一个。技术新动作先学会再进阶。

单次表现差先查睡眠、休息、器械、疼痛和实际执行。连续出现完成下降、疲劳累积或执行困难，再减训练量/强度或调整结构；给出明确下一次剂量与复查条件，不自动每四周减量。

## 有氧与饮食配合

有氧基础可用“能说话但难以唱歌”辅助判断中等强度，不固定同一个心率给所有人。没有基础时从短时、可耐受剂量开始，逐步接近公共健康活动建议；不一次把公共建议全部塞进训练。力量与有氧按主要目标排序，可同日或分开，避免高负荷腿练与高冲击间歇相互挤压。

减脂先了解摄入记录、活动和体重/腰围趋势；拍照 App 是估算摄入，不是实测消耗。观察同条件多日趋势，不按单日涨跌或周末一顿饭调整。无关用户目标时不扩展成饮食咨询；需要具体饮食或医疗建议时另行核实可靠来源和适用条件。
