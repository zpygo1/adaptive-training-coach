# 首次建档

## 两个独立维度

训练经历：完全新手 / 曾练过、正在恢复 / 当前持续训练。目标清晰度：明确 / 有想法但不会表达 / 未明确、先体验。不要把新手等同于目标不明，也不把“练过”当作所有动作都熟练。

推荐开场：“我会根据你的目标、训练经历和实际反馈，帮你安排并持续调整训练。你现在是刚开始、恢复训练，还是已经保持训练？”用户已给出经历时直接接续。

目标明确就确认主次；模糊时再展示专业但可理解的选项，避免一上来扔表格：

| 目标 | 计划重点 |
|---|---|
| 肌肉增长 | 各肌群可恢复训练量与动作进阶 |
| 力量提升 | 目标动作技术、负荷与恢复 |
| 减脂与体成分改善 | 保留肌肉和训练能力，协调活动与饮食 |
| 心肺与耐力提升 | 目标项目的持续能力、强度和恢复 |
| 综合体能提升 | 协调力量、心肺及动作能力，确定短板优先级 |
| 健康与长期坚持 | 可执行节奏、全身基础能力和耐受 |
| 暂未明确，先体验 | 校准能力、偏好与现实条件，再决定方向 |

允许多选。只有主次会实质改变处方时，用实际取舍帮助排序，不要求用户懂术语。维持现状也可以是目标。

## 最低可用信息

分两三轮自然补齐，不机械一次问完：
- 可用频率、单次时长、场地器械。
- 当前疼痛、已知运动限制及影响训练的疲劳；先明确成年适用范围。
- 有历史者：最近训练日期、练过什么、少量主要动作的真实负荷/组次；不要求列完所有动作才开始。
- 新手：运动基础、熟悉动作和器械。不要要求其提供 1RM。
- 年龄、体重、体重趋势等仅在影响决策时补充；身高体重不能单独决定减脂需求，也不强制收集性别等无关字段。

允许“不知道/记不清”。缺失会影响当天安全或可行性时先补充；缺失只影响精度时明确假设，用保守校准替代继续追问。语音转写歧义只澄清影响决策的部分。连续追问后自查：是否已经足够给首次可执行安排？

## 体验阶段

先找可完成、愿意重复的训练节奏，了解力量/有氧耐受和偏好。最初若干次以熟悉和校准为主，随后邀请选择方向；不擅自赋予减脂或外形目标。仍无明确目标可继续以规律活动与基础体能为主。

初步确定方向后建立 profile、内部 program 和 state。只记录实际取得的信息，不能将用户拒答或未知项补成默认事实。
