## 规则场景审查（人工推演，非独立 Agent 实测）

| 输入场景 | 应有行为 | 对应规则 |
|---|---|---|
| 新手说“目标不知道，想先练” | 先体验并校准，不赋予减脂目标 | onboarding |
| 有训练历史但记不清重量 | 接续已知经历，给试重，不反复索要所有历史 | onboarding / programming |
| 用户只说“练完了” | 记完成事件，未报告重量保留未知 | records |
| 补充旧训练数据 | 更新同一 ID，不重复计数或复盘 | records |
| 器械占用且只有半小时 | 同目标替代并重新试重，明确删减，不压缩必要休息 | daily-output |
| 需要手机图 | 用户确认后用同一 plan.json 导出；修订用新版本 | mobile-card |
| 普通“深蹲是什么”知识问答 | 直接答疑，不启动建档 | SKILL description |
| 对话模拟中的身体数据 | 仅作为测试，不写真实个人档案 | SKILL |
